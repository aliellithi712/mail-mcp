# MCP Email Server
This is the MCP Email Server, a Node.js application built with Express and TypeScript. It handles email-related tasks and integrates with the Model Context Protocol (MCP) SDK and extensions.

## Features
- Handles email-related tasks
- Integrates with the Model Context Protocol (MCP) SDK
- Supports MCP extensions
- Built with Express and TypeScript
- Uses environment variables for configuration
- Provides a development and production build setup
- Uses Pino for logging
- Supports TypeScript type checking
- Provides a ready-to-use development environment with `tsx`
- Supports environment-based configuration for different deployment scenarios
- Provides a structured project layout for maintainability
- Easy to extend with additional MCP extensions
